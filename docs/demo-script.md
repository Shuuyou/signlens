# SignLens · 3 分钟 Demo 脚本

> 目标：让评委在 3 分钟内看到「读你的合同 → 给判断 → 每条可回指 → 改一个事实结论翻转」。
> 演示入口：本地 `http://127.0.0.1:8010/`，线上为魔搭创空间 HTTPS 链接。

## 0:00–0:20 钩子

「一个学生创业者，明天要给 1688 供应商打 20400 元预付款。合同 9 条，他只看懂了总价。我们让他先做一次体检。」

点击首页演示卡「1688 供应商 30% 预付款采购」→ 载入案例。

## 0:20–0:50 输入

指出三样东西：合同全文 651 字、对方公司名、聊天记录里那句「合同就是走个流程，不用改」。
「聊天记录不是装饰——它用来识别口头承诺和合同文本之间的落差。」

点击「开始体检」。

## 0:50–1:20 分析

五个阶段依次亮起：解析条款 → 核查主体 → 匹配法条 → 生成建议 → 出报告。
口头补充：17 条条款、40 条硬规则、30 组法条；主体核查走公开源，演示数据已脱敏。

## 1:20–1:50 结论与风险

- 结论横幅：「建议不签」，置信度 90%。
- 一句话理由：9 条高风险条款 + 对方有被执行记录 + 行政处罚记录。
- 点开第一条「预付款比例过高」：为什么、对应条款原文、法条原文（民法典第 527 条）、改法。
- 侧栏主体核查：2 条未履行被执行、实缴 0、参保 3 人。

## 1:50–2:30 如果…会怎样（高潮）

滚动到「谈判推演」：
1. 勾选「对方书面补充交货日期与验收标准」→ 风险敞口下降；
2. 勾选「预付款降至 10%，尾款验收后支付」；
3. 勾选「争议解决改到公司所在地法院」；
4. 点「模拟全部让步」→ 结论从「不签」翻转为「可签/可谈」，风险卡片同步标记「推演中已缓释」。

台词：「我们卖的不是一份报告，是一个会随证据改变结论的决策过程。评委可以现场改一个事实，看结论怎么变。」

## 2:30–2:50 交付物

- 滚动到「谈判清单」：P0/P1 分级，8 条，可直接拿去谈。
- 点「打印 / 导出 PDF」：一页纸谈判单 + 完整报告。
- 指一下来源列表：gsxt、zxgk、wenshu、creditchina、flk.npc.gov.cn。

## 2:50–3:00 收尾

「企查查回答『这家公司是什么』；我们回答『以你的情况，这单该不该做，哪几条会坑你，什么会改变结论』。数据可以买，判断不能。」

## 备用方案

- 网络/服务异常：切到预录的 3 分钟视频；报告 HTML 已可离线打印。
- 评委要求看别的合同：用输入页粘贴一段真实合同（不要用客户敏感信息），30 秒内出结果。
- 被问「和企查查/大模型有什么区别」：现场展示「点条款回原文 + 点法条看效力 + 改事实翻转结论」三件事。
- 被问「数据合法吗」：只用官方公开源；演示数据脱敏；产品定位风险提示，不构成法律意见。
