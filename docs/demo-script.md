# SignLens · 3 分钟 Demo 脚本

> 目标：让评委在 3 分钟内看到「读你的合同 → 给判断 → 每条可回指 → 谈妥一项，结论跟着变」。
> 演示入口：本地 `http://127.0.0.1:8010/`，线上为魔搭创空间 HTTPS 链接。
> 录制脚本 `scripts/record_demo.py` 与本文一致，字幕直接渲染在页面里。

## 0:00–0:20 钩子

「一个学生创业者，明天要给 1688 供应商打 20400 元预付款。合同 9 条，他只看懂了总价。我们让他先做一次体检。」

点击首页演示卡「1688 供应商 30% 预付款采购」→ 载入案例。

## 0:20–0:50 输入

指出三样东西：合同全文 651 字、对方公司名、聊天记录里那句「合同就是走个流程，不用改」。
「聊天记录不是装饰——它用来识别口头承诺和合同文本之间的落差。」

点击「开始体检」。

## 0:50–1:10 一句话结论

报告第一屏只有一句话：「先别签。最要紧的是预付款比例过高和未约定明确交付日期，而且对方有被执行记录和行政处罚。」
下面一行说明读了 17 段条款、命中 12 条风险、对照 5 个公开来源。

## 1:10–2:20 先让对方答应这几件事（高潮）

滚动到清单，逐项勾选：
1. 勾「对方书面补充交货日期与验收标准」→ 高风险 9 → 6，一句话结论里的原因随之更换；
2. 再勾「预付款降至 10%」和「争议改到公司所在地法院」→ 高风险只剩 2 条；
3. 点「全选」→ 标签从「建议不签」变为「先谈再签」，并注明由哪个结论改判；
   结论文案仍提醒：对方有被执行记录，付款前要担保。

台词：「我们卖的不是一份报告，是一个会随谈判进展改变结论的决策过程。」

## 2:20–2:50 风险明细与合同全文

- 风险默认只展开最要紧的一条：为什么、合同里的原话、建议改成什么、民法典第 527 条原文。
- 点「在合同全文里看」打开合同原文，命中风险的条款按等级标色；点一句标色文字，回到对应风险。
- 「对方是谁」：2 条未履行被执行记录、1 条虚假宣传行政处罚排在最前，其余核查项折叠。

## 2:50–3:00 收尾

页脚一句：规则引擎生成，不构成法律意见；主体信息为脱敏演示数据。
可「复制成谈判清单」带去见对方，也可导出 PDF。

「企查查回答『这家公司是什么』；我们回答『这单该不该签、谈到什么程度能签』。数据可以买，判断不能。」

## 备用方案

- 网络/服务异常：切到预录的 3 分钟视频；报告可离线打印。
- 评委要求看别的合同：用输入页粘贴一段合同（不要用客户敏感信息），30 秒内出结果。
- 被问「和企查查/大模型有什么区别」：现场展示「点条款回原文 + 展开法条原文 + 勾一项结论就变」三件事。
- 被问「数据合法吗」：演示数据脱敏；真实模式走用户上传的营业执照/信用报告 + 官方公开源核验入口，不爬取、不绕验证码；产品定位风险提示，不构成法律意见。
