# SignLens 路演 deck

12 页、1280×720 的自包含 HTML 幻灯片，直接打印成 16:9 PDF（13.333in × 7.5in）。
只有 `index.html` 一个文件，CSS 内联，没有构建步骤、没有 JS 依赖（仅一个「打印」按钮）。

## 怎么导出 PDF

推荐 Chrome / Edge：

1. 打开 `deck/index.html`（双击即可，用 `file://` 也能加载图片和字体）。
2. `Ctrl+P` → 目标「另存为 PDF」。
3. 关键设置：
   - 纸张：**自定义 13.333in × 7.5in**（或选「横向 + A4」也能看，但会有白边）
   - 边距：**无**
   - 缩放：**默认 / 100%**
   - **勾选「背景图形」**（否则纸色、青柠色块、深绿页会丢）
   - 取消「页眉和页脚」
4. 应得 12 页，尺寸 960 × 540 pt。

macOS 预览 / Keynote 导入可能会出现字体替换，优先用 Chromium 内核浏览器打印。

## 依赖（不要单独移动 index.html）

`index.html` 用相对路径引用仓库里的两处素材。**必须保持在 `signlens/deck/` 下**，否则中文字体和截图会掉：

| 引用 | 路径 | 用途 |
|---|---|---|
| 标题字体 | `../frontend/public/fonts/smiley-sans-v2.0.1.woff2` | 得意黑，只有 400 一个字重 |
| 截图 | `../.shots/ui_report_top.png`、`../.shots/ui_report_risks.png` | 第 6 页 |

字体加载失败会回退到系统黑体，版式不塌，但标题会失去得意黑的味道。

## 设计口径

- 纸 `#faf9f5`、墨 `#24261f`、青柠 `#d5ed83`、绿 `#286544`、红 `#c0392b`、琥珀 `#a8721c`；
  与 `frontend/src/design/mingcha-tokens.css` 同一套 token。
- 标题得意黑 42px（封面 66px），正文系统黑体，**合同条款原文用法条宋体**（`Songti SC / SimSun`），
  报告里的引文一律宋体，和产品内报告保持一致的阅读感。
- 每页固定页眉（`02 · 一个具体的人`）+ 页脚（`SIGNLENS · 签前体检` / 页码）。
- 正文区用 `space-between` 分配留白，所以每页底部不会出现「内容堆在上半页」的空洞；
  改文案时如果删掉一整块，记得补一块，否则该页会明显变空。

## 内容口径（重要）

这版 deck 刻意不编数字，答辩时可以直接摊开讲：

- **可直接引用**：1270 万（教育部 2025 届高校毕业生规模）；40 条规则 / 8 部法律 / 30 组法条；
  17 条条款、9 条 / 651 字、5 个公开源——都来自 `data/` 与 `docs/contracts.md`，可复查。
- **标注「待验证」**：培训贷与租房押金的规模数字（样本不足，不做估算）、99/199/299 定价、复购假设 1.4 份 / 学期。
- **未落实、已按设想写**：基地订阅（无成交）、199 解读档、执业律师法条审校（尚未落实）。
- 团队页已填 Shuuyou、6TDooo（杭电具身智能实验室）。

金额、公司名、执行记录全部来自 `data/cases/supplier-deposit.json`（演示数据已脱敏），
页面上的 `DEMO` 标记与「不构成法律意见」声明是产品边界的一部分，不建议删。
